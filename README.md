# GeoBiz Uzbekistan

**Благополучность, безопасность, экология и бизнес-потенциал районов Узбекистана
на настоящей карте Google Maps.**

GeoBiz Uzbekistan — кроссплатформенное десктоп- и мобильное приложение на
**C++23 / Qt 6**, которое показывает административные территории Узбекистана
(области, города, районы, махалли) на реальной карте Google Maps, раскрашивает
их по цветовым зонам благополучности и риска и отвечает на бизнес-вопросы через
встроенный локальный ИИ-помощник.

> ⚠️ **Принцип честности данных.** Приложение **не выдумывает** показатели. Если
> данных недостаточно, территория помечается как «Недостаточно данных» и **не
> раскрашивается**. Реальные показатели появляются только при подключении
> реального источника данных (см. [docs/DATA_SCHEMA.md](docs/DATA_SCHEMA.md)).

---

## Возможности

- 🗺️ **Настоящая карта Google Maps** через Qt WebEngine (десктоп) / Qt WebView
  (Android) — Maps JavaScript API, Places API, Geocoding API.
- 🎨 **Семь цветовых зон** с прозрачной заливкой полигонов:
  🟢 зелёная · 🟣 фиолетовая · 🔵 синяя · ⚫ серая · 🟡 жёлтая · 🟠 оранжевая ·
  🔴 красная. Серая/жёлтая/оранжевая/красная показывают предупреждение.
- 📋 **Карточка района**: название, рейтинг, безопасность, экология,
  инфраструктура, уровень сервиса, бизнес-потенциал, население, рекомендации.
- 🤖 **Локальный ИИ-помощник** (полностью офлайн): «Где лучше открыть кофейню?»,
  «Где меньше конкуренция?», «Самые богатые районы Ташкента», «Лучшие районы для
  ресторана», «Самые безопасные районы».
- 🔎 Поиск и навигация по областям, городам, районам и махаллям.
- 🎛️ **Material Design 3**, адаптивный интерфейс (десктоп ↔ телефон), тёмная и
  светлая темы.
- ⚡ Многопоточная асинхронная загрузка и классификация, аппаратное ускорение
  Qt Quick, кэширование геометрии на стороне карты.

## Технологический стек

- **Язык:** только современный C++23 (никаких PHP/Python/Java/C#/Electron/
  Node.js/Flutter/React Native/React/.NET).
- **UI:** Qt 6.9+ (Qt Quick / QML), стиль Material.
- **Карты:** исключительно Google Maps (JS API + Places + Geocoding) внутри
  Qt WebEngine / Qt WebView.
- **Сборка:** CMake (+ CPack, qt_add_qml_module, qt_add_translations).

## Быстрый старт

### 1. Ключ Google Maps API

Получите ключ в Google Cloud Console и включите **Maps JavaScript API**,
**Places API** и **Geocoding API**. Передайте его приложению одним из способов:

```bash
export GEOBIZ_GOOGLE_MAPS_API_KEY="AIza..."
```

…или введите ключ в самом приложении при первом запуске (он сохранится локально).

### 2. Сборка ядра и тестов (без Qt, быстро)

```bash
cmake --preset core-only
cmake --build --preset core-only
ctest --preset core-only
```

### 3. Сборка десктоп-приложения (нужен Qt 6.7+ с WebEngine)

```bash
cmake --preset desktop-release
cmake --build --preset desktop-release
./build/GeoBizUzbekistan
```

Подробные инструкции по всем платформам — в [docs/BUILD.md](docs/BUILD.md).

## Цветовые зоны

| Зона | Значение | Предупреждение |
|------|----------|----------------|
| 🟢 Зелёная | Богатые районы, развитая инфраструктура, безопасность, экология | — |
| 🟣 Фиолетовая | Бизнес-класс: современные дома, кафе, рестораны, высокий сервис | — |
| 🔵 Синяя | Бюджетное жильё, ограниченная инфраструктура | — |
| ⚫ Серая | Высокая преступность, неблагоприятная обстановка | ⚠ |
| 🟡 Жёлтая | Опасность для здоровья (ЛЭП, свалки, загрязнение, шум) | ⚠ |
| 🟠 Оранжевая | Строительные/геологические риски (просадка, слабый грунт) | ⚠ |
| 🔴 Красная | Опасные для жизни территории, техногенный риск, ЧС | ⚠ |

Логика классификации прозрачна и детерминирована — см.
`include/geobiz/core/Classifier.hpp`. Риски имеют приоритет над качеством: богатый,
но техногенно опасный район будет красным.

## Данные

Комплект поставки содержит **только реальный административный каркас** Узбекистана
(названия и приблизительные координаты центров — открытые географические данные).
Показатели качества намеренно отсутствуют, поэтому такие территории отображаются
как «Недостаточно данных». Чтобы получить раскраску и рейтинги, подключите
реальный набор данных по схеме из [docs/DATA_SCHEMA.md](docs/DATA_SCHEMA.md).
