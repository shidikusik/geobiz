# Формат данных территорий

Приложение загружает территории из JSON-файла (`resources/data/uzbekistan.json`
по умолчанию, либо внешний файл через `dataset_path` в конфиге). Разбор выполняет
`geobiz::data::LocalDatasetProvider`.

> **Главное правило: не выдумывать данные.** Любой показатель может отсутствовать.
> Отсутствующий показатель отображается как «Недостаточно данных», а район с
> недостаточным набором данных **не раскрашивается** (остаётся нейтральным).

## Корневой объект

```jsonc
{
  "source": "Название источника данных",      // атрибуция для интерфейса
  "note": "Пояснение (необязательно)",
  "districts": [ /* массив территорий */ ]
}
```

## Территория (`district`)

```jsonc
{
  "id": "uz.tashkent-city.yunusabad",          // уникальный стабильный id
  "parentId": "uz.tashkent-city",              // id родителя ("" для страны)
  "name": { "ru": "Юнусабадский район",
            "uz": "Yunusobod tumani",
            "en": "Yunusabad" },
  "level": "country|region|city|district|mahalla",
  "center": { "lat": 41.3675, "lng": 69.2889 },// обязательно

  // --- всё ниже необязательно ---
  "boundary": [ [41.35, 69.27], [41.38, 69.27], [41.38, 69.31] ],
  // либо [{ "lat": .., "lng": .. }, ...]; если задано — рисуется полигон,
  // иначе — маркер в центре.

  "population": { "value": 300000, "source": "Госкомстат РУз" },

  "indicators": {                              // все значения в шкале 0..100
    "safety":            { "value": 78, "source": "..." },
    "ecology":           { "value": 65, "source": "..." },
    "infrastructure":    { "value": 80, "source": "..." },
    "service":           { "value": 72, "source": "..." },
    "businessPotential": { "value": 85, "source": "..." },
    "wealth":            { "value": 76, "source": "..." },

    // Показатели риска (выше = опаснее). Наличие высокого значения переводит
    // территорию в соответствующую зону риска независимо от позитивных метрик.
    "healthHazard":      { "value": 10, "source": "..." },  // → жёлтая
    "constructionRisk":  { "value": 15, "source": "..." },  // → оранжевая
    "technogenicRisk":   { "value": 5,  "source": "..." },  // → красная
    "crime":             { "value": 20, "source": "..." }   // → серая
  },

  "recommendations": [                          // необязательно; если не заданы,
    "Подходит для открытия кафе и ресторанов."  // выводятся выведенные из данных
  ]
}
```

## Как показатели превращаются в зону

См. `include/geobiz/core/Classifier.hpp`. Кратко:

1. **Зоны риска имеют приоритет** (в порядке важности): `technogenicRisk` ≥ 60 →
   🔴, `constructionRisk` ≥ 60 → 🟠, `healthHazard` ≥ 60 → 🟡, `crime` ≥ 60 → ⚫.
   Риск учитывается только если соответствующий показатель **присутствует** —
   отсутствие риска не порождает ложную опасность.
2. Иначе считается взвешенный композитный рейтинг по присутствующим позитивным
   показателям. Нужно **не менее трёх** из них, иначе — «Недостаточно данных».
3. Рейтинг ≥ 72 → 🟢; сильный бизнес-профиль или рейтинг ≥ 58 → 🟣; иначе → 🔵.

Пороги настраиваются через `ClassifierConfig`.

## Источники, которые можно подключить

Архитектура (`geobiz::data::IDataProvider`) рассчитана на несколько источников:

- Google Maps / Places / Geocoding (обогащение сервисными данными);
- открытые государственные данные Узбекистана;
- статистические данные (население, доходы);
- экологические данные (качество воздуха, шум);
- геологические данные (грунты, риск просадки);
- данные об инфраструктуре.

Первый зарегистрированный провайдер считается источником истины (набор
территорий), остальные — обогащающими (`IDataProvider::enrich`).
